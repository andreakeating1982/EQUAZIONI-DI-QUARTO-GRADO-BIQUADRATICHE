VARIANTI POSSIBILI (tramite l'IA):

  * Cambiare il grado dell'equazione (2, 4, 6, 8...)
    -> scripts/clone_app.py + docs/grado.md

  * Disequazioni di qualsiasi grado (studio del segno)
    -> docs/disequazioni.md

  * Equazioni/disequazioni fratte (C.E. + verifica)
    -> docs/fratte.md

  * Cambiare la LINGUA (inglese, spagnolo, francese)
    -> docs/lingua.md

  * Quiz con set di domande (VERO/FALSO, 3 o 4 opzioni)
    -> docs/quiz.md


TRASFERIRE SU RENDER (via GitHub):

  1. Crea un repository su github.com
  2. Carica TUTTI i file di questo pacchetto (root del repo)
  3. Vai su render.com -> New -> Blueprint
  4. Collega il repository: Render legge render.yaml
     e crea il Web Service automaticamente.

  Dettagli: DEPLOY-RENDER.md


STRUTTURA DEL PROGETTO:

  client/            Frontend React + Vite + Tailwind
  server/            Server Express (serving statico)
  shared/            Costanti condivise
  docs/              Riferimenti per le varianti (grado, disequazioni,
                     fratte, lingua, quiz)
  scripts/           clone_app.py (clonazione grado)
  cornice-dinamica/  Embed Blogger (lite + base64)
  render.yaml        Blueprint Render
  .github/workflows/ CI (build automatica)
